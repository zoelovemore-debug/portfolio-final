# Zwitwa Netselo — Portfolio

A standalone, dependency-free portfolio site (HTML, CSS, vanilla JS).

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Host on GitHub Pages

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**, branch `main`, folder `/ (root)`
3. Your site will be live at `https://zoelovemore-debug.github.io/portfolio-final/`
